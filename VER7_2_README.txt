Runaway's Ver7.2 / v10
JRA単勝オッズ自動取得 + 妙味自動判定

主な変更
- 調教判定表の「年月日・場所・R・馬番・馬名」からJRA該当レースを特定
- JRA開催日程ページから「回次・日次」を自動判定
- Selenium/ChromiumでJRA詳細出馬表を開き、馬名照合で単勝オッズ・人気を取得
- 注目レース（S評価馬のいるレース）だけ初回自動取得
- 「🔄 オッズ再取得」で発走前の最新単勝へ更新
- 分析結果にも「単勝オッズ」「人気」を追加
- ★は最終スコアだけではなく、現在単勝オッズが妙味条件に入った時だけ表示
- オッズ未発売/取得失敗時は「-」のまま分析を継続

妙味条件
芝 ★★★: 最終スコア8.5以上 + 単勝20〜50倍
芝 ★★ : 最終スコア8.25以上 + 単勝10〜20倍
ダート ★★★: 最終スコア8.0以上 + 単勝10〜20倍
ダート ★★ : 最終スコア7.5以上 + 単勝10〜20倍

注意
- JRA側のDOM/URL仕様変更時は取得ロジックの調整が必要です。
- 発売前はオッズが表示されないため、発売開始後に「オッズ再取得」を押してください。

Sire Analyzer 統合版 Ver6.1

今回の修正
1. 芝クッション値判定を数値方式だけに固定
   - ±0.3 通常
   - ±0.5 補完
   - ±0.8 低信頼度参考
   - 旧「クッション値判定」固定区分へのフォールバックを廃止

2. クッション入力変更時の古い分析結果を自動破棄
   - Streamlit session_state に前回結果が残って見える問題を防止
   - 条件変更後は「分析開始」を再実行

3. 分析結果へ確認用項目を追加
   - 当日クッション値
   - クッション評価
   - クッション幅
   - クッション母数
   - クッション信頼度
   - 本人クッション評価
   - 本人クッション母数
   - 本人クッション幅

4. 不要な旧評価を削除
   - 旧最終判定
   - 統計評価
   - StatScore
   - 推奨度

5. Ver6最終評価のみを主評価として表示
   - S / A / B / C / 降格
   - 最終スコア
   - 評価理由

6. 調教師・騎手表示は維持
   - トップページ注目レース
   - 分析結果

地雷ラップは引き続き強制「降格」。

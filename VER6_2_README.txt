重要:
このZIPは「リポジトリ直下へ展開・上書き」する形式です。
ZIP内に余分な親フォルダを作っていません。

- クッション値は芝マスタの「クッション値」実数列だけを使用

- ±0.3 → ±0.5 → ±0.8 のみ
- 分析結果の列名を「父馬クッション適性」へ変更
- 「当日クッション値」「クッション判定範囲」「クッション母数」
  「クッション信頼度」を表示
- 画面上に Ver6.2 クッション実数判定 と表示
- 旧判定評価 / StatScore / 推奨度は表示しない

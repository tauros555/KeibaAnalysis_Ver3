Sire Analyzer 統合版 Ver6
=========================

主な変更
--------
1. トップページ「本日の注目レース」に調教師名・騎手名を表示
2. 通常の「分析結果」に調教師名・騎手名を表示
3. 第14M～14Pの検証結果に基づく芝/ダート別の最終評価層を追加
   - S / A / B / C / 降格
   - 地雷ラップは他要素に関係なく強制「降格」
4. 旧Ver5 StatScore / 旧最終判定は比較用として残す
5. 芝クッション値は実数入力へ変更
   - ±0.3 通常
   - 母数不足時 ±0.5
   - さらに不足時 ±0.8（低信頼度参考）
6. 芝で馬自身の過去クッション適性を追加
   - 0走 評価なし
   - 1～2走 参考
   - 3走以上 正式評価
7. ダート馬場状態適性の最終重みは第14Pで採用した 0.5
8. マスターの「芝ダ / 芝・ダ」列名揺れを読込時に自動吸収
9. ZIP内のCSVファイル名をコードが期待する日本語名へ正規化

最終評価の基本重み
------------------
芝:
  調教本命 6
  調教コース判定 2
  A3高勝率Lap 2
  父馬×競馬場×距離 3
  補完 3
  救済 0.5
  枠馬番支持 1
  坂警告 -1相当（芝は弱く反映）
  クッション 2
  本人クッション 1（父馬クッションプラス時は二重加点しない）

ダート:
  調教本命 6
  調教コース判定 1
  A3高勝率Lap 2
  父馬×競馬場×距離 3
  補完 3
  救済 0.5
  枠馬番支持 0.5
  坂マイナス警告 -1
  馬場状態適性 0.5

評価閾値
--------
芝: S 6.55以上 / A 4.70以上 / B 3.00以上 / C それ未満
ダート: S 4.85以上 / A 3.75以上 / B 2.75以上 / C それ未満
地雷ラップ: スコアに関係なく「降格」

起動
----
streamlit run app.py

注意
----
・調教師名・騎手名は調教判定表の「調教師」「騎手」列を正本にします。
・手入力モードでも調教判定表と馬名照合できれば表示されます。照合できない場合は「-」です。
・旧StatScoreは互換表示であり、Ver6の最終S/A/B/C判定とは別物です。
